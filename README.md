# InsightIQ – AI-Powered Business Intelligence Dashboard

InsightIQ is a full-stack web application that lets users upload a business sales dataset (CSV), automatically cleans and analyzes it, visualizes key performance metrics on an interactive dashboard, and uses the **Groq API (Llama 3.3)** to generate AI-powered business insights and recommendations.

Built as a portfolio project to demonstrate practical skills in data analysis, business intelligence, data visualization, backend development, REST API design, and AI integration.

---

## Features

- **CSV Upload** — Upload a sales dataset with validation for file format, required columns, and empty files. Upload history is stored in MySQL.
- **Automatic Data Cleaning** — Duplicate removal, missing value handling, date parsing, and numeric field validation using Pandas.
- **Interactive Dashboard** — KPI cards for Total Sales, Total Profit, Total Orders, Total Customers, Best Selling Category, and Highest Revenue Region.
- **Interactive Charts** — Monthly Sales Trend, Sales by Region, Sales by Category, Top 10 Products, and Profit by Category, built with Plotly.
- **Dynamic Filters** — Filter all analytics by Year, Region, and Category.
- **AI Business Insights** — Executive Summary, Key Trends, Best Performing Products, Weak Performing Regions, and Recommendations, generated by Groq.
- **PDF Reports** — Download a combined KPI + AI Insights report as a PDF.
- **Modern UI** — Responsive sidebar-navigation dashboard with a blue-and-white professional theme, built with Bootstrap 5.

## Installation Guide

### Prerequisites
- Python 3.10+
- MySQL Server 8.0+
- A Groq API (Llama 3.3) key ([Google AI Studio](https://aistudio.google.com/))

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/InsightIQ.git
cd InsightIQ
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure environment variables
```bash
cp .env.example .env
```
Then edit `.env` with your MySQL credentials and Groq API key (see below).

### 5. Set up the database
```sql
CREATE DATABASE insightiq_db;
```
Tables are created automatically on first run via SQLAlchemy — no manual migrations needed.

### 6. Run the application
```bash
cd backend
uvicorn app.main:app --reload
```

### 7. Open the app
Visit **http://localhost:8000** in your browser. Interactive API docs are available at **http://localhost:8000/docs**.

## Environment Variables

| Variable         | Description                                      |
|-------------------|--------------------------------------------------|
| `DB_HOST`          | MySQL host (default: `localhost`)                |
| `DB_PORT`          | MySQL port (default: `3306`)                      |
| `DB_USER`          | MySQL username                                    |
| `DB_PASSWORD`      | MySQL password                                    |
| `DB_NAME`          | Database name (e.g. `insightiq_db`)               |
| `DATABASE_URL`     | Full SQLAlchemy connection string                 |
| `GEMINI_API_KEY`   | Your Groq API (Llama 3.3) key                        |
| `APP_ENV`          | `development` or `production`                     |
| `APP_SECRET_KEY`   | Random secret key for the app                      |

See `.env.example` for a ready-to-copy template.

## Database Setup

InsightIQ uses two MySQL tables, defined as SQLAlchemy models in `backend/app/models.py`:

- **`users`** — id, username, email, hashed_password, created_at
- **`uploaded_datasets`** — id, filename, file_path, row_count, total_sales, total_profit, uploaded_at, owner_id, ai_insights (cached)

Tables are auto-created on startup via `Base.metadata.create_all()`.
